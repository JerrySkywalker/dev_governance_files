# Agent Context Router

`context-manifest-v1.json` is the machine-readable routing source for Agents and
adapter generators. It distinguishes automatic instructions, active normative
sources, conditional playbooks, historical references, archives, and generated
files.

An ignore file is not a security boundary. Tool-specific files such as
`.aiderignore`, `CLAUDE.md`, and Copilot instructions are generated adapters.
The shared source remains `AGENTS.md` plus this manifest.
