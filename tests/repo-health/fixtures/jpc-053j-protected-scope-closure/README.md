# Exact 053J nonactivation fixture

`accepted/` contains sanitized, byte-identical copies of the retained 053J
lease and the immutable local evidence used to prove its terminal state. The
fixture is deliberately stored without Git text normalization because the
production contract binds the original SHA-256 bytes.

These files are test evidence only. They grant no Owner authority, permit no
real-task-root closeout, and must never be used for production contact or a
new protected transaction. Tests create a disposable shadow authorization at
runtime and exercise only disposable task roots.
